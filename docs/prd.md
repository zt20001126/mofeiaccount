# 产品需求文档 (PRD) - 简易本地记账软件

## 1. 项目概述
* **项目名称：** 简易本地记账工具 (Local Bookkeeping Tool)
* **产品定位：** 一款面向单人或小微企业用户的纯本地、单机版记账桌面软件。
* **核心痛点：** 解决用户没有服务器、不愿将财务数据上传到云端，但又需要比直接操作纯 Excel 更加智能化（如自动算结余、便捷管理图片凭证、防止误操作）的记账需求。
* **技术架构：** Tauri + Vue3/React + TypeScript (数据通过前端库实时读写本地 Excel 文件)。

---

## 2. 核心业务流程
```

[打开软件] -> [首次使用：初始化选择工作目录] | v [进入主页] -> [展示历史账目列表] (支持查看、修改) | +--> [点击“新增记账”] -> [填写表单/选择凭证图片] -> [点击保存] -> [自动计算结余并写入Excel]

```

## 3. 功能需求详情

### 3.1 目录初始化与配置文件管理
* **场景描述：** 软件第一次启动或用户想更换账本位置时，需要指定一个工作目录。
* **具体需求：**
  * 软件首次启动时，检测是否存在配置文件。若不存在，弹出系统文件夹选择框，要求用户**选择一个工作目录**（如 `D:/我的记账/`）。
  * 选定目录后，软件自动在该目录下创建：
    * `账本.xlsx`：用于存放所有账目流水。
    * `/vouchers/` 文件夹：用于存放用户上传的凭证图片。
  * 软件本地（应用沙盒内）保存该目录路径，下次打开直接加载，无需重复选择。

### 3.2 记账数据结构定义 (Data Schema)
表格及软件底层数据必须包含以下 8 个字段：

| 字段名称 | 变量名 (TS) | 数据类型 | 约束/生成规则 | Excel 列名 |
| :--- | :--- | :--- | :--- | :--- |
| **账目ID** | `id` | String | 系统自动生成的唯一流水号 (如 `TX202606060001`) | 账目ID |
| **记账时间** | `time` | String | 格式：`YYYY-MM-DD HH:mm:ss`，默认获取当前系统时间 | 记账时间 |
| **客户名称** | `customerName` | String | 必填文本 | 客户名称 |
| **收款金额** | `income` | Number | 必填数字，默认 `0` | 收款金额 |
| **支出金额** | `expense` | Number | 必填数字，默认 `0` | 支出金额 |
| **结余金额** | `balance` | Number | **置灰不可填**。算法：`上一笔结余 + 本次收款 - 本次支出` | 结余金额 |
| **说明/备注** | `description` | String | 选填文本 | 说明 |
| **凭证** | `voucher` | String | 存放图片复制到本地后的**相对路径**（不存绝对路径） | 凭证 |

### 3.3 核心功能模块

#### 模块一：新增记账 (Add Record)
* **界面组成：** 表单输入页（客户名称、收款、支出、说明、凭证上传按钮）。
* **交互规则：**
  1. 用户输入收款或支出金额时，界面实时联动更新“结余金额”预览。
  2. 点击“选择凭证”按钮，调用系统文件选择器，限制只能选择图片格式（`.jpg`, `.png`）。
  3. 点击“保存”按钮后，软件执行以下操作：
     * **图片转存：** 将选中的图片复制到工作目录下的 `/vouchers/` 文件夹中，重命名为 `[账目ID].png`。
     * **Excel追加：** 使用 TypeScript 的 `xlsx` 库打开工作目录下的 `账本.xlsx`，在末尾追加这一行新数据，并保存文件。
     * **刷新列表：** 界面提示保存成功，并刷新历史列表。

#### 模块二：查看与修改账目 (View & Edit Record)
* **主界面：** 以表格（Table）形式分页或滚动展示 `账本.xlsx` 里的所有数据。
* **查看需求：** 
  * 列表清晰展示所有字段。
  * 点击“凭证”列的图片名称或缩略图，软件能**弹窗预览**这张本地凭证图片。
* **修改需求：**
  * 每行账目右侧设有“修改”按钮。
  * 点击“修改”，弹出弹窗（内容与新增表单一致，但回显已有数据）。
  * **联动修改限制：** 用户若修改了历史某笔账的“收款/支出”，**软件必须自动重新计算该笔账之后所有账目的“结余金额”**，并整体重新写入 Excel，确保账目逻辑正确。

## 4. 非功能性需求与注意事项

1. **数据持久化安全：** 
   由于没有服务器数据库，所有的增删改操作都是直接复写 `账本.xlsx` 文件。代码中必须做好异常处理（Try-Catch），防止在写入过程中软件被强制关闭导致 Excel 文件损坏。
2. **凭证路径依赖：**
   Excel 中记录的凭证必须是**相对路径**（如 `./vouchers/TX202606060001.png`）。这样即使客户把整个工作目录拷贝到别的电脑上，软件依然能正常读取和预览图片。
3. **性能体验：**
